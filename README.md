# EventKampus v1.0 — Release Notes

## 📱 Tentang Aplikasi
**EventKampus** adalah aplikasi Android untuk informasi dan pendaftaran kegiatan kampus Universitas Malikussaleh (UNIMAL).

Dibuat untuk mata kuliah **Pemrograman Mobile** — Teknik Informatika UNIMAL.

---

## ✨ Fitur Utama

| Fitur | Keterangan |
|---|---|
| 🔐 Autentikasi | Login & Register akun mahasiswa |
| 📋 Daftar Kegiatan | Seminar, Workshop, Lomba, Kepanitiaan |
| 🔍 Pencarian & Filter | Filter kategori, format, harga, kuota |
| 🎟️ E-Tiket + QR Code | Tiket digital dengan QR Code presensi |
| 🗺️ Google Maps | Navigasi ke lokasi kegiatan |
| 🔔 Notifikasi Lokal | Konfirmasi pendaftaran & pengingat jadwal |
| 🌐 WebView | Portal website UNIMAL in-app |
| 👤 Role Admin/User | Admin dapat tambah/edit/hapus kegiatan |
| 🌙 Dark Mode | Mendukung mode gelap sistem |

## 📋 Spesifikasi

- **Min SDK**: Android 7.0 (API 24)
- **Target SDK**: Android 15 (API 37)  
- **Arsitektur**: SQLite lokal + SharedPreferences
- **Bahasa**: Kotlin

---

## 📦 Instalasi

1. Download file `EventKampus-v1.0.apk` di bawah
2. Buka file APK di perangkat Android
3. Jika muncul peringatan *"Install unknown apps"*, izinkan instalasi dari sumber ini
4. Ikuti proses instalasi
5. Buka aplikasi dan login menggunakan akun demo di atas
